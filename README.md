# Исход — прототип рынка прогнозов

Статический интерфейс на HTML, CSS и JavaScript. Один вымышленный рынок, иллюстративная история вероятности, покупка и продажа долей за виртуальные баллы. Данные сохраняются в localStorage браузера. Реальных платежей и рыночных котировок нет.

Запуск из этой папки: `python3 -m http.server 4173 --directory dist`.

Исходники: `dist/index.html`, `dist/styles.css`, `dist/app.js`. Для добавления событий в дальнейшем потребуется выделить модель рынка из текущего демонстрационного интерфейса.
